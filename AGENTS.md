# AGENTS.md

## Project Overview

Static single-page e-commerce website (Vanilla HTML/CSS/JS).

## Commands

- **Run**: Open `index.html` directly in browser (no build step required)
- **Dev**: Use Live Server or similar to serve the file

## Structure

- `index.html` - Complete SPA with all HTML, CSS, JS inline
- `SPEC.md` - Project specification document

## Notes

- No package manager, no build system
- All code contained in single `index.html` file
- Shopping cart persists via `localStorage`
